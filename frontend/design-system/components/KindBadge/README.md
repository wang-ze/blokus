# KindBadge

A small outlined pill naming what kind of player this is: LLM, bot or human.

From `_kind_badge(kind)`. Static rendition.

- `caption` size, `bk-muted` text, 1px `bk-border`, `radius-pill`, padding `space-1` × `space-6`.
- Labels: `llm` → "LLM", `bot` → "bot", `human` → "human"; the shared color's card uses "no score".
