# Swatch

A 12px rounded square in a player color, placed before the color's name.

The `.bk-swatch` + `.bk-bg-<color>` classes in `render.py`. Static rendition.

- Size `swatch`, `radius-3`, vertically centered in text.
- Always pair it with the color's name. Red and Green differ only in hue, and Yellow barely shows on light grounds.
